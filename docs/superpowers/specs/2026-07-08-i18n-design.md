# 中英文多语言界面（i18n）

**Date:** 2026-07-08
**Status:** Design

---

## 目标

为 Resource Ontology Visualiser 添加中/英文双语支持，用户可通过界面按钮手动切换语言，偏好持久化到 `localStorage`。

---

## 架构

### 文件结构

```
client/src/lib/
  i18n.ts              ← locale store、t() 函数、语言切换逻辑
  locales/
    en.json            ← 英文语言包
    zh.json            ← 中文语言包
```

### `i18n.ts` 核心逻辑

```ts
// locale: $state('en' | 'zh')，初始从 localStorage 读，默认 'en'
// t(key): 查当前字典，key 不存在回退到 en 兜底
// setLocale(lang): 更新 locale + 写 localStorage + 动态 import() JSON
// initLocale(): onMount 时调用，异步加载初始语言包
```

### 语言包 `en.json` / `zh.json`

Key 用点分隔命名空间（`app.title`、`stats.classes`、`details.subClasses`）。带变量的字符串用 `{n}` 占位符。

### 语言切换按钮

放在 header 右侧、文件下拉框左边。两个小按钮 `中` / `EN`，当前选中语言高亮。

## 错误处理

| 场景 | 行为 |
|------|------|
| JSON 文件加载失败 | `t()` 回退到 `en` 内联兜底字典 |
| `localStorage` 不可用 | 静默降级，内存中保存语言偏好 |
| key 不存在于当前语言包 | 查 `en` 字典，仍不存在则返回 key 本身 |
| 语言包 JSON 格式错误 | `try/catch` 兜底，回退到 `en` |

---

## 设计决策

- 语言包用 JSON 动态 `import()`，仅加载当前语言，减小 bundle
- 不用第三方 i18n 库，保持零依赖
- key 命名用 `.` 分隔命名空间，清晰可维护
- 变量用 `{n}` 占位 + `.replace()`，简单够用
